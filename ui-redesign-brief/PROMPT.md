## 一、项目背景

- 产品：ST-TagLab，SillyTavern（浏览器内角色扮演前端）的扩展面板，用途是 NovelAI 生图工作流：画师串/提示词管理、Vibe Transfer、参数调节、图库管理、画师对比、水印工坊。
- 技术栈：**Vue 3（`<script setup lang="ts">`）+ Vite + TypeScript，无任何 UI 库，纯手写 CSS**。
- 运行形态：嵌入宿主页面的浮动面板，宽度受限，不是独立网页；需在窄宽度下保持信息密度。
- 主题：三套（跟随宿主 / 昼象牙白 / 夜海军黑），全部颜色与圆角、动效通过 `--tlb-*` CSS 变量驱动（见 `source/styles/theme.css`）。

## 三、面板清单与核心任务（不得删减功能）

1. **GenPanel 生成页（主面板）**：双栏——左列画师串预设/画师串输入/正面提示词/快捷输入+生成按钮/负面提示词（折叠）；右列 Vibe Transfer 列表与生图参数（折叠）；底部生成结果横滑浏览；含放大编辑弹层。
2. **SettingsPanel 设置页**：NAI 接入点管理（预设下拉+增存改删）、接口地址/Key、测试连接；提示词助手配置；同步；快捷输入设置；资料导入导出；常用资源。
3. **GalleryPanel 图库**：历史记录网格、收藏、筛选、回填参数再次生成。
4. **GalleryCompareModal / ArtistCompare**：多图/多画师串横向对比。
5. **WatermarkStudio 水印工坊**：左预览舞台 + 右控制区（模式、样式组预设、贴纸、文字参数、平铺、九宫格定位）。
6. **PreviewModal 大图预览**：图片放大 + 标签操作。
7. **FloatingPanel / InputActions / Icon**：浮动容器、输入框附属操作、图标。

- 保持窄面板场景的高密度可用性，按钮常用高度约 26–32px。
- 必须延续 `--tlb-*` 设计令牌体系，新组件一律使用变量，禁止硬编码颜色；昼/夜/跟随宿主三套主题都要成立。
- 保留现有信息架构与全部功能入口，允许重组布局、层级、折叠方式与视觉样式。
